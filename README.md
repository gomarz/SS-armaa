A large-scale content and systems mod for [Starsector](http://fractalsoftworks.com), adding transforming mechs, strikecraft with custom combat AI, a named-pilot progression system, and a scripted narrative campaign.

## Features

- **~30 new ships**, from capital ships down to mechs and fighters. Did I mention mechs?
- **Transforming units.** The GuarDUAL/Zwei line shifts between flight and combat modes mid-battle, with dedicated transition AI.
- **The WINGCOM Suite.** A hullmod that procedurally generates named pilots for every fighter wing. Pilots gain levels across the campaign and have a large pool of semi-contextual combat barks that fire in response to what's actually happening in the fight.
- **Strikecraft mechanics.** Docking, repair and refit pools, spare chassis respawn, and boarding pod deployment, all emulating carrier fighter behavior at ship scale.
- **Custom ship systems with bespoke AI.** 30+ systems, each with its own AI implementation so the fleet uses them sensibly under autopilot rather than firing them at random.
- **Narrative campaign content.** 
- **Custom missions**

  
**Requirements:** Starsector 0.98, [LazyLib](https://fractalsoftworks.com/forum/index.php?topic=5444.0), [MagicLib](https://fractalsoftworks.com/forum/index.php?topic=13718.0)
